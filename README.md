## Project Goal

Routine data inspection often involves repeating the same tasks: checking column types, identifying missing values, calculating summary statistics, and producing initial plots.

This project aims to package those tasks into a small, reusable Python tool.

The intended users include students, researchers, and analysts who need a repeatable first-pass inspection of tabular data.

## Planned Features

The following features describe the intended first version. **They should not be considered implemented until the corresponding code exists and has been tested.**

- Read a user-supplied CSV file.
- Report the number of rows and columns.
- Display column names and data types.
- Identify missing values and duplicate rows.
- Calculate descriptive statistics for numerical columns.
- Generate basic plots for suitable columns.
- Export a Markdown analysis report.
- Optionally save a cleaned dataset after explicit user selection.
- Provide useful error messages for invalid or malformed input files.

## Proposed Workflow

1. Load a CSV file.
2. Inspect its structure and column types.
3. Summarise missing values, duplicates, and numerical columns.
4. Generate appropriate plots.
5. Write a report and optional output files.

## Proposed Output

The intended output directory may look like this:

```text
results/
├── report.md
├── summary_statistics.csv
├── missing_values.csv
└── plots/
    ├── numerical_distribution.png
    └── correlation_matrix.png
```

This is a proposed structure, not a description of files currently generated by the program. The final output should depend on which analyses are implemented and which columns are present.

## Development Setup

### 1. Clone the repository

Once this project has been created on GitHub:

```bash
git clone https://github.com/LuceilIsRight/CSV-Analysis-Assistant.git
cd CSV-Analysis-Assistant
```

### 2. Create a virtual environment

**Windows (PowerShell):**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**Linux/macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install the proposed dependencies

After creating the initial implementation, install its dependencies:

```bash
python -m pip install --upgrade pip
python -m pip install pandas numpy matplotlib pytest
```

A tested dependency file should be added once the project's environment is stable.

## Planned Usage

The intended interface is:

```bash
python main.py sample_data.csv --output results/
```

This is a proposed command, not a working interface yet. The entry-point script, argument parsing, output directory, and report generation must be implemented before this command can be used.

## Data Handling Principles

The implementation should follow these principles:

- Preserve the original input file.
- Never silently remove rows or columns.
- Make cleaning operations explicit.
- Report the number of changed or removed records.
- Handle missing and mixed-type data carefully.
- Avoid printing sensitive data unnecessarily.
- Keep outputs reproducible and clearly labelled.

## Testing Plan

Planned tests include:

- Valid CSV input.
- Missing or empty files.
- Numerical and categorical columns.
- Missing values and duplicate rows.
- Unexpected data types.
- Output-directory creation.
- Report generation.
- Validation of optional cleaning operations.

Test results should be documented only after the tests have actually been run.

## Limitations

The intended tool is for exploratory data analysis. It will not automatically determine whether data is scientifically valid, whether outliers are erroneous, or whether a particular statistical conclusion is justified.

Users remain responsible for evaluating cleaning decisions and interpreting results.
